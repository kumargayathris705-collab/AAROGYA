# 🌿 AAROGYA – Care Today. Thrive Tomorrow.

AAROGYA is a healthcare and medication management web application designed to help users manage their daily medications, track health records, and stay connected with caregivers.

The application provides a simple, mobile-friendly interface with support for Android and iOS installation.

## ✨ Features

- **User Authentication:** Secure registration and login using Firebase Authentication.
- **Medication Management:** Add, edit and manage medication details.
- **Daily Tracking:** Record daily health check-ins.
- **Health Journey:** Maintain and download health records in CSV format.
- **Caregiver Connection:** Connect users with caregivers through invitation codes.
- **Responsive Interface:** Designed for mobile devices and desktop screens.
- **Installable Application:** Supports Progressive Web App (PWA) installation on Android and iOS.

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Firebase Authentication
- Cloud Firestore
- Progressive Web App (PWA)

## 📱 Platform Compatibility

- Android
- iOS
- Desktop browsers

## 🚀 Installation

AAROGYA can be accessed through a web browser and installed on supported devices.

**Android:**
1. Open the application in Google Chrome.
2. Select Install App.
3. Follow the installation instructions.

**iOS:**
1. Open the application in Safari.
2. Tap the Share button.
3. Select Add to Home Screen.

## 🔐 Backend & Security

- Firebase Authentication for account management.
- Cloud Firestore for storing application data.
- Firestore security rules for access control.

**Note:** Firebase integration is currently a preview and requires testing before using real medical information.
